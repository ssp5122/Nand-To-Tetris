## Personalised specification

The assignment defines `K` as the last two digits of the roll number.

- `K = 26`
- Starting screen row: `26`
- Height: `20` rows (rows 26 through 45)
- Width: `16 × ((K mod 4) + 1) = 16 × 3 = 48` pixels
- First screen word: `SCREEN + 32 × 26 = 16384 + 832 = 17216`
- Assembler extension: `K mod 3 = 2`, so the assembler warns when a label is declared more than once.

## Assemble

Run these commands from this folder:

```bash
python assembler.py Box.asm
```

The command writes `Box.hack` in the same folder. The `.hack` file included here was generated from the included `Box.asm` using the included `assembler.py`.

## Run in the CPU Emulator

1. Open the Nand2Tetris CPU Emulator.
2. Use the ROM folder icon to load `Box.hack`.
3. Enable the keyboard.
4. Run the program.
5. Hold a key to draw the black rectangle; release it to clear the same rectangle.

## Viva points

- One screen row contains 32 words.
- One word contains 16 pixels.
- Three consecutive words draw 48 horizontal pixels.
- Adding 32 to the screen address moves down by one screen row.
- The keyboard is memory-mapped at address 24576 (`KBD`).
- Writing `-1` fills a 16-bit screen word with ones (black); writing `0` clears it (white).
